# Python Assignments & Practical Exercises

A comprehensive collection of Python coursework, assignments, and practical exercises covering fundamental programming concepts, built-in data types, operators, control flow, loops, functions, and data processing with lists, tuples, sets, dictionaries, and strings.

## 📚 Topics Covered

### 1. Python Operators
- Arithmetic operators
- Compound assignment operators
- Relational and comparison operators
- Logical operators (`and`, `or`, `not`)
- Identity operators (`is`, `is not`) vs equality (`==`)
- Membership operators (`in`, `not in`)
- Unary operations and increment/decrement behavior in Python

### 2. Conditional Statements
Real-world Practical problems using `if`, `elif`, `else`, and nested conditions:
- ATM withdrawal system
- Electricity bill calculation with surcharge
- Employee bonus eligibility and calculation
- Student result and division system
- Bank loan eligibility checker
- E-commerce discount engine
- Role-based login and access control
- Movie ticket booking and availability
- Positive, negative, or zero number classifier
- Voting eligibility and campus ID verification

### 3. Loops & Iteration
Exercises using `for` loops, `while` loops, ranges, counters, and accumulators:
- Even and odd numbers
- Multiples of a number
- Sum of numbers, even numbers, and odd numbers
- Multiplication tables
- Divisibility checks
- Counting even and odd numbers
- Reversing list elements
- Finding the largest and smallest values
- Counting vowels and spaces
- Counting positive and negative numbers
- Character occurrence counting

### 4. Pattern Printing with Nested Loops
- Solid rectangle pattern
- Right-angled star and number triangles
- Repeated number triangle
- Floyd's triangle
- Binary alternating triangle
- Alphabet and repeated alphabet triangles
- Inverted star and number triangles
- Centered star pyramid
- Diamond star pattern
- Palindromic number pyramid
- Patterns using `while` loops

### 5. List Comprehension
Practice with filtering, mapping, conditional expressions, nested lists, and practical datasets:
- Filtering numbers by value and divisibility
- Filtering names by length
- Squaring even numbers
- Pass/fail classification
- Celsius-to-Fahrenheit conversion
- Replacing numbers with `Even` or `Odd`
- Replacing negative numbers with zero
- Tiered product discounts
- Cleaning and formatting names
- Flattening a 2D matrix
- E-commerce product filtering and discounts
- Separating bank deposits and withdrawals
- Extracting student and employee records

### 6. Python String Methods & Operations
- String creation, length, and immutability
- Positive and negative indexing
- Slicing, repetition, and concatenation
- String traversal using loops
- Case conversion: `upper()`, `lower()`, `title()`, `capitalize()`, `swapcase()`
- Whitespace removal: `strip()`, `lstrip()`, `rstrip()`
- Searching with `find()`, `index()`, and `count()`
- Prefix and suffix checks: `startswith()`, `endswith()`
- Character validation: `isalpha()`, `isdigit()`, `isalnum()`, `isspace()`
- Splitting and joining strings
- Replacing substrings
- String formatting with f-strings and `.format()`

### 7. Tuples
- Tuple creation and the comma rule
- Single-element tuples
- Immutability
- Indexing, slicing, and traversal
- Tuple packing and unpacking
- Extended unpacking with `*`
- Handling unpacking errors
- Tuple methods: `count()` and `index()`
- Built-in functions: `len()`, `min()`, `max()`, and `sum()`

### 8. Sets
- Set creation and empty sets
- Duplicate elimination
- Unordered nature of sets
- Adding and updating elements
- Removing elements with `remove()`, `discard()`, and `pop()`
- Clearing a set
- Union, intersection, difference, and symmetric difference

### 9. Dictionaries
**Fundamentals and methods**
- Dictionary creation using `{}` and `dict()`
- Key uniqueness and duplicate values
- Updating and accessing key-value pairs
- Safe retrieval with `get()`
- Inspection with `len()`, `keys()`, `values()`, and `items()`
- Removing entries with `pop()`, `popitem()`, and `clear()`
- Reference assignment vs shallow copy using `copy()`
- Membership checks with `in` and `not in`

- Attendance and academic division evaluation
